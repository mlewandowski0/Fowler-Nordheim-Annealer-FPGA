A fixed accepted-flip budget measures update throughput. A target-score comparison measures solver performance. The NumPy baseline below uses the authors’ public implementation on an Intel Core Ultra 9 275HX; its candidate policy, noise arithmetic and cooling differ from the FPGA.

MAKE IT YOURS

Try a different starting point.

The public replay needs no board. Browser runs use a software QUBO annealer and are labeled separately.

Only the clues are used to initialize the solver.

01

Encode the choices.

Nine possible digits for each of 81 cells become 729 binary variables. Clues fix some bits and rule out others.

02

Let conflicts cost.

A reward favors filled cells. Penalties discourage repeated digits and multiple numbers in one cell. An energy of −81 is a valid complete grid.

03

Keep the work local.

Small hardware units propose changes in parallel. One accepted flip is broadcast so each unit updates its own state.
