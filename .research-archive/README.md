# Local historical archive

Generated Vivado/Vitis projects, unrelated experiments, caches, and editor files
were removed from the current tracked tree during private release cleanup.
They remain in earlier Git history. On the original development machine, the
files were also moved here, preserving their original relative paths.

Everything here except this README is ignored and is not included in commits
or source packages. Local `moved-files.json` lists the moves.
`website-git-metadata/` contains the former nested website's Git metadata; the
website's actual files are now tracked directly by the outer repository.

The maintained build does not depend on this folder. Required LUTs, graph
inputs, historical logs, and selected source excerpts remain at their original
tracked paths so provenance hashes and audits continue to work.
