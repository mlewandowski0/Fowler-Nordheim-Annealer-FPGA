## Verified results and honest claims

1. **Restored G15 clock**: static 800-variable, 25 × 32 core on XC7Z020.
   Actual PYNQ clock 142.857143 MHz; Vivado constraint 145.455 MHz, setup slack
   +0.032 ns, hold +0.040 ns. Resources: 25,430 LUT, 14,243 registers,
   7.5 BRAM tiles, 25 DSP. Vivado power ~1.991 W is an estimate only.
   Independently checked cut 3050. Matched seed-1 50 MHz→142.857 MHz gain
   2.857×; median 13.165M accepted flips/s. See `results/performance/` and
   `docs/performance.md`. Polling overshoot is retained and normalized.
2. **Gset**: 39 full graphs, 117 main board runs, three seeds and exactly
   10M accepted flips, at 100 MHz. Covers 37/59 original supplementary entries
   plus G8/G9; best-of-three >=99% historical reference on all 37. Retain all
   seed ranges, exclusions, and unsuccessful target trials. Runtime-loadable
   signed 800-node GST1, unsigned 1000-node GST2, unsigned 2000-node GST3.
   GST3 uses 140/140 BRAM tiles. No cropping. See `docs/benchmarks.md`.
3. **CPU**: fresh named upstream NumPy implementation on Intel Core Ultra 9
   275HX, pinned one logical CPU / one BLAS thread. Fixed accepted-flip and
   shared-target measurements exist. This is not a claim against the fastest
   CPU implementation; algorithms and numeric representations differ.
   `results/comparison_cpu/`, `results/comparison_cpu_tts30/`.
4. **SpiNNaker2**: published runtimes WERE located in arXiv 2406.05224v2,
   Section S5.2, Figure S3a, PDF pages 37–38. Approximate graph readings:
   G4 ~2400 s, G11/G15 ~2600 s, rounded to 100 s. Exact iteration count and
   equivalent event semantics are unconfirmed. No matched platform speedup!
   Original 504/2460/20-second constants and 66×/324× claims are withdrawn.
   Bare-metal ~40× statement must not be applied again to the runtime bars.
   The 2026 follow-up's generic NeuroSA 540/525/480 s table is not a validated
   SpiNNaker2 timing table. Upstream public GitHub history had no raw SPI logs.
   See `docs/spinnaker_comparison.md`, `results/spinnaker_comparison/sources.json`.
   Own 30-seed-setting FPGA trials per G4/G11/G15: full-reference successes
   0/30, 17/30, 5/30; descriptive frequencies, not proven i.i.d. TTS99.
5. **Fixed native iterations**: separate ITR1 100 MHz overlay; nine board runs
   at exactly 100M arbitration iterations. Median G4/G11/G15 active times
   1.28877598 / 2.59741726 / 2.28417898 s, cut ranges 11622–11641 /
   562–564 / 3047–3050. Count includes active S_WAIT flip/no-flip decisions,
   not individual unit candidate checks or update/drain cycles. Up to 25
   units propose concurrently. Exact identities:
   `iterations = accepted_flips + rejected_iterations`;
   `active_cycles = iterations + 6*accepted_flips`.
   This does not establish a matched SPI budget. See `docs/iterations.md`.
6. **Sudoku/demo**: 729-bit formulation following arXiv 2403.04816, separate
   100 MHz overlays. Classic seed 1 and paper 24-clue seed 2 solve on hardware;
   unsuccessful paper seed 1 remains visible. Clamps reduce free variables;
   do not call this an unconstrained 729-free-variable solve. Viewer includes
   recorded board trajectories, MAX-CUT, and a separately labeled real browser
   Metropolis solver. Capture pauses for readout: replay times are not benchmark
   throughput. See `docs/demo.md`, `docs/sudoku.md`.
